# Goldwright changelog

## 0.2.1

- **Sales you can trust:** tooltips, `/gw price` and the Crafting panel now show **proven sales** ("sold ~420/day"): stacks that got smaller because someone bought part of them, or cheaper stacks a buyer cleared out. Items with no proven sales still show the looser estimate, marked "(est.)". That includes gear, which can't be partly bought. Blizzard doesn't publish sales, so every number is worked out from the listings. How it works: **goldwright.app/faq**.
