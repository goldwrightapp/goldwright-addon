# Contributing to Goldwright

Thanks for helping make Goldwright better.

## Bug reports and ideas: yes, please

- **Bugs:** [open an issue](https://github.com/goldwrightapp/goldwright-addon/issues/new/choose) and pick **Bug report**. Search the open issues first; if yours is already there, add a comment or a 👍 instead.
- **Ideas:** pick **Feature request**.
- One problem per issue, please. Screenshots and the exact Lua error text help the most.

## Pull requests: by arrangement only

Goldwright is **All Rights Reserved** (see [LICENSE](LICENSE)), not open source. This repository is a published copy of each release, so pull requests can't be merged here as they are.

If you'd like to contribute code, open an issue first and describe what you have in mind. If it fits, we'll agree on how to take it in. Please don't send unrequested pull requests: they will be closed.

## Security

If you found something that could harm players (for example a way to make the add-on act without a click), don't post the details in a public issue. Use **Report a vulnerability** on this repository's [Security tab](https://github.com/goldwrightapp/goldwright-addon/security) instead: only the maintainers can read it.
